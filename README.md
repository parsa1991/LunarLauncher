# LUNAR LAUNCHER

**Your games. Your space.**

Lunar is a desktop game launcher focused on bringing your library, gaming activity, and social experience into one unified interface. Built around a dark, glass-inspired design, it combines a minimal aesthetic with features designed for everyday use.

## Overview

Lunar is designed to make your game library feel like part of a cohesive desktop experience, rather than just another collection of game covers. Its interface combines clean layouts, subtle animations, translucent surfaces, and a dark visual identity.

## Features

**Game Library**

Browse your collection through a visual library built around game artwork, streamlined navigation, and a clean interface. Lunar's design keeps your games at the center of the experience.

**Lunar Social**

A built-in social experience that brings friends and conversations into the launcher.

* Direct messages and group conversations
* Friends and online presence
* Gaming activity and currently playing status
* User profiles and profile customization
* Reactions and interactive messaging
* A dedicated social drawer integrated into the main interface

**Lunar+**

Lunar's premium membership experience, designed to offer additional personalization and exclusive profile features.

* Premium profile customization
* Exclusive visual effects and profile styling
* Animated profile elements and banners where supported
* Additional ways to personalize your identity within Lunar

Premium features and availability depend on the current release.

**Personalization**

A visual experience built around Lunar's signature dark aesthetic, with theme options and profile customization designed to make the launcher feel personal.

**Desktop Experience**

A dedicated desktop application with integrated navigation, a unified interface, and an update workflow for supported release builds.
